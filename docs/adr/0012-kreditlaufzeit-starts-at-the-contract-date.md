# Kreditlaufzeit starts at the Vertragsdatum

A Kredit has two lengths, and they start on different dates. Kreditlaufzeit is the contractual span from the Vertragsdatum to the agreed end; a Kredit that ends only when notice is given has no Kreditlaufzeit. Bisherige Kreditlaufzeit is the time already run, from the first Einzahlung until Rückzahlung, or until today while the Kredit is still open. An Ansparvertrag does not move either span. We kept both because one column was hiding which date the length was measured from.
